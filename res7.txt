## Recommended fix

Since you want to keep nginx, make your firewall forward external `443` to nginx's `30443`.

On your server:

```bash
sudo firewall-cmd --permanent \
  --add-forward-port=port=443:proto=tcp:toport=30443

sudo firewall-cmd --reload
```

Also HTTP:

```bash
sudo firewall-cmd --permanent \
  --add-forward-port=port=80:proto=tcp:toport=30080

sudo firewall-cmd --reload
```

Then verify:

```bash
sudo firewall-cmd --list-forward-ports
```

You should see:

```text
port=443:proto=tcp:toport=30443
port=80:proto=tcp:toport=30080
```
